ExMachina 将交互接入、任务编排、模型调用与工具执行分层。个体、组、技能和 SOUL 通过数据定义，编排契约连接各层行为。

## 系统分层

```text
WebUI / 桌面端 / CLI / 消息通道
                 │ REST / WebSocket
                 ▼
         exm-gateway
   路由 · 鉴权 · 事件流 · 静态托管
                 │
                 ▼
           exm-core
   Orchestrator  目标收拢与裁决
   Scheduler     DAG 与并发池
   AgentRuntime  模型与工具循环
   MemoryStore   分层记忆
   ToolGateway   审批、沙箱与审计
   LlmProvider   模型协议与档案池
                 │
                 ▼
      模型端点 / 工具 / 本地存储
```

网关进程提供 REST、WebSocket 事件流与 WebUI 托管。CLI 是另一种交互入口，复用核心运行机制。

## 六步任务循环

| 阶段 | 行为 | 主要产物 |
| --- | --- | --- |
| 收拢 | 接收目标，锁定边界与约束 | 任务目标与任务账 |
| 规划 | 选择直答、单链、并行或裁决路径 | OrchestratorPlan |
| 派发 | 按依赖与能力调度子个体 | DispatchOrder |
| 回流 | 检查结构与业务验收条件 | SyncReport |
| 裁决 | 显式处理冲突或阻塞 | 裁决节点与依据 |
| 收束 | 汇总结果，写入三账与记忆 | 结构化结论 |

单个智能体直接进入会话与工具循环，省去组内调度。组模式由指挥体按任务重量选择路径。

### DAG 调度

任务节点包含依赖、目标、优先级与验收口径。调度器只在前置依赖满足后派发节点，并通过并发池限制同时运行的任务。

回流冲突或受阻时，可追加裁决节点。分歧保留在记录里，避免用最终文字静默覆盖不同依据。

## 三账

- **任务账**：目标、验收、约束与禁令。
- **证据账**：结论依据与 A–D 证据等级。
- **风险账**：未决断言、影响、阻断和回退路径。

三账随任务循环更新，连接输入、过程与最终交付。详细字段见[协议与契约](/docs/contracts)。

## 记忆与隔离

群体记忆共享决策、证据与偏好；个体记忆保存各自的教训与技巧。派发时注入当前个体可见的私有记忆与群体共享记忆。

组同时承担会话、工作区和编成的隔离边界。文件访问与工具执行还受工具网关、工作区路径策略和执行权限限制。

## 模型解析

默认模型依次从个体、所属组与全局档案解析。提供商档案可以声明模型、Key 池和失败回退链。

支持 OpenAI 兼容、Anthropic、Gemini 和 Azure OpenAI 协议。配置入口见[安装指南](/docs/installation#连接模型服务)。

## 存储与交付

当前项目 README 将持久化描述为文档型 fsdb，默认数据目录为 `.exmachina/data`。存储通过 repository 接口隔离，具体结构随项目实现演进。

编成、人设、技能等定义位于 `entities/`。运行配置与数据位于工作区的 `.exmachina/`，不应作为官网素材或公开资源上传。

## 扩展边界

MCP、插件和远端执行通过明确的接入协议与能力声明连接核心。工具调用继续走统一的权限、审批与审计链路。

阅读[插件开发指南](/docs/plugins)了解插件能力包；阅读[安全与权限](/docs/security)了解执行边界。
